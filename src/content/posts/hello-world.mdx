## 为什么选择 Astro

Astro 默认输出纯静态 HTML，几乎没有 JavaScript 开销，非常适合以内容为主的博客。文章正文支持 Markdown 与 MDX，因此可以混写公式、代码与自定义组件。

## 数学公式

行内公式直接写在句子中，例如质能方程 $E = mc^2$，以及二次方程求根公式 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$。

块级公式使用 `$$ ... $$`：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi}
$$

矩阵也可以正常渲染：

$$
\mathbf{A} =
\begin{pmatrix}
a_{11} & a_{12} \\
a_{21} & a_{22}
\end{pmatrix}
$$

## 代码块

```ts
// 一个简单的例子：计算斐波那契数列
function fib(n: number): number {
  let [a, b] = [0, 1];
  for (let i = 0; i < n; i++) {
    [a, b] = [b, a + b];
  }
  return a;
}

console.log(fib(10)); // 55
```
